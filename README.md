# 파수대 연구 해설 조사 도우미

[English](README.en.md) | **한국어**

「파수대」 연구 기사의 항별 해설을 **wol.jw.org에서만** 조사해서 **기본해설 / 부가해설 / 연구해설**로 정리해 주는 AI 도우미입니다.

> 이 저장소는 비공개입니다. 초대받은 분만 볼 수 있으니 링크나 파일을 다른 곳에 공개하지 말아 주세요.

---

## 무엇을 해 주나요?

- 기사 링크를 주면 항마다 다음 세 가지 해설을 만듭니다.
  - **기본해설**: 연구 질문에 바로 답하는 1~2문장
  - **부가해설**: 같은 항의 다른 성구나 다른 각도를 다루는 1~2문장
  - **연구해설**: WOL 출판물, 성구 각주, 「통찰」 등을 근거로 한 해설. 출처를 함께 적습니다.
- 사람이 조사하듯 WOL 검색창에 키워드를 넣고, 검색 결과를 열어 읽은 뒤 정리합니다.
- 조사 과정(검색 키워드 → 결과 수 → 열어 본 자료 → 찾은 내용)을 표로 보여 줍니다. 그래서 같은 경로로 직접 다시 확인할 수 있습니다.
- **jw.org / wol.jw.org 외의 사이트는 사용하지 않습니다.** 확인하지 못한 내용은 "출처 확인 못 함"이라고 표시합니다.

## 결과 예시

| 순서 | 검색 키워드 | 결과 | 열어 본 자료 | 찾은 내용 |
|---|---|---|---|---|
| 1 | 빛의 천사로 가장 | 38건 | 「통찰」 1권 "사탄" | 사탄은 "본색과 목적을 감추고" 접근함 |
| 2 | 의심 바다 물결 | 33건 | 「파수대」 2021년 2월호 26-31면 | 의심은 닻을 연결하는 쇠사슬의 녹과 같음 |

**1항: 사탄은 우리가 여호와께 등을 돌리게 하기 위해 어떤 방법을 사용합니까?**
- **기본해설**: 사탄은 우리가 여호와와 가까이 지내는 한 이길 수 없다는 걸 압니다. 그래서 여호와와 예수께서 우리를 사랑하신다는 점에 의문을 갖게 만들어 우리가 스스로 등을 돌리게 하려고 합니다.
- **부가해설**: 사탄은 우리가 "사랑받을 가치가 없다"고 믿게 하려 합니다. 하지만 로마 8:38, 39은 어떤 것도 하느님의 사랑에서 우리를 갈라놓을 수 없다고 말합니다. (「파수대」 2019년 9월호 15항)
- **연구해설**: 야고보 1:6은 의심하는 사람을 출렁이는 바다 물결에 비유합니다. 희망이 닻이라면 믿음은 닻에 연결된 쇠사슬인데, 의심을 해결하지 않으면 그 사슬이 녹슬어 약해집니다. (「파수대」 2021년 2월호 15-16항)

## 사용 방법

### 방법 A. Claude (추천)

**Claude 데스크톱 앱이나 claude.ai에서 쓰는 경우**
1. 이 저장소의 [`watchtower-comment-research.skill`](watchtower-comment-research.skill) 파일을 내려받습니다. 파일을 연 뒤 오른쪽 위의 다운로드 버튼을 누르면 됩니다.
2. Claude에서 **설정 → 기능(Capabilities) → 스킬(Skills)**로 가서 파일을 업로드합니다.
   - 메뉴 이름은 앱 버전에 따라 조금 다를 수 있습니다.
3. 새 대화에서 다음처럼 요청합니다.
   ```
   이번 주 파수대 기사야: https://wol.jw.org/ko/wol/d/r8/lp-ko/(기사번호)
   1항부터 3항까지 기본해설, 부가해설, 연구해설로 정리해 줘.
   ```
4. Claude 데스크톱 앱(Code 탭)에서는 내장 브라우저 창에서 조사 과정을 직접 지켜볼 수 있습니다.

**Claude Code(터미널)에서 쓰는 경우**
```bash
git clone https://github.com/suinegyzal/watchtower-comment-research.git
mkdir -p ~/.claude/skills
cp -R watchtower-comment-research/watchtower-comment-research ~/.claude/skills/
```

### 방법 B. ChatGPT, Gemini 등 다른 AI

1. [`prompts/파수대-해설-조사-프롬프트.md`](prompts/파수대-해설-조사-프롬프트.md)를 엽니다. 「프롬프트 본문」 부분을 복사합니다.
2. 복사한 내용을 다음 위치에 붙여 넣습니다.
   - **ChatGPT**: 맞춤 GPT 만들기 → 지침(Instructions). 또는 프로젝트 지침에 넣어도 됩니다.
   - **Gemini**: Gem 만들기 → 안내(Instructions)
   - 그 밖의 AI는 대화 첫 메시지로 붙여 넣으면 됩니다.
3. 해당 AI의 **웹 검색 / 브라우징 기능을 켭니다.** 이 기능이 꺼져 있으면 wol.jw.org를 열 수 없습니다.
4. 기사 링크를 보내 요청합니다.

> 다른 AI는 조사 과정을 화면으로 보여 주지 못할 수 있습니다. 그럴 때는 결과에 붙은 조사 과정 표와 출처로 확인하세요.

## 사용 팁

- **처음에는 2~3항씩** 요청하세요. 한 번에 18항을 모두 요청하면 조사가 얕아집니다.
- 개인 경험이 들어가면 좋은 곳에는 `[개인 경험]` 자리만 표시해 줍니다. 내용은 직접 채워 넣으세요.
- 해설이 길면 "더 짧게, 30초 안에"라고 요청하세요.
- **최종 확인은 꼭 직접 하세요.** 표에 적힌 출처를 WOL에서 열어 보고, 문맥이 맞는지 확인한 다음 사용하세요.
