# 파수대 연구 해설 조사 도우미

[English](README.en.md) | **한국어**

「파수대」 기사 링크를 주면 AI가 **wol.jw.org에서만** 직접 검색하고 읽어서 항마다 **기본해설 / 부가해설 / 연구해설**을 출처와 함께 정리해 줍니다.

![조사 과정](docs/images/research-flow.gif)

---

## 어디에서 쓰나요?

| 사용하는 곳 | 추천 | 특징 |
|---|---|---|
| **Claude Code** (Claude 데스크톱 앱의 Code 탭) | ⭐ 가장 추천 | 브라우저 창에서 AI가 조사하는 과정을 직접 볼 수 있습니다 |
| **Codex** (ChatGPT의 코딩 도구) | ○ 추천 | 조사 과정 표와 출처로 확인합니다 |
| **Claude 채팅 + 크롬 확장 프로그램** | ○ 추천 | 크롬에서 AI가 WOL을 검색하는 과정을 직접 볼 수 있습니다 (유료 요금제 필요) |
| **Claude 채팅** (확장 프로그램 없이) | △ 가능 | 조사 과정이 화면에 보이지 않고, 정확도가 조금 떨어질 수 있습니다 |

## 설치 방법

### ① Claude 채팅
1. [`watchtower-comment-research.skill`](watchtower-comment-research.skill) 파일을 내려받습니다. 링크를 연 뒤 오른쪽 위의 다운로드 버튼(↓)을 누르면 됩니다.
2. Claude에서 **설정 → 기능(Capabilities) → 스킬(Skills)**로 가서 파일을 올립니다.
3. 같은 화면에서 **웹 검색**이 켜져 있는지 확인합니다.

### ② Claude Code (데스크톱 앱 Code 탭)
1. Claude 데스크톱 앱에서 **Code** 탭을 엽니다.
2. 아래 문장을 그대로 붙여 넣고 보냅니다.
   ```
   이 스킬을 내 Claude에 설치해 줘: https://github.com/suinegyzal/watchtower-comment-research
   ```
3. 허락을 물어보면 승인하고, 설치가 끝나면 **새 세션**을 엽니다.

> ①에서 스킬을 이미 올렸다면 Code 탭에서도 바로 보일 수 있습니다. 보이지 않을 때만 ②를 하세요.

### ③ Codex
1. Codex를 엽니다.
2. 아래 문장을 그대로 붙여 넣고 보냅니다.
   ```
   이 스킬을 설치해 줘: https://github.com/suinegyzal/watchtower-comment-research
   ```
3. 허락을 물어보면 승인하고, 설치가 끝나면 Codex를 다시 시작합니다.
4. Codex 설정에서 **웹 검색**을 켭니다.

### ④ 크롬 확장 프로그램 (Claude in Chrome)
Claude 채팅에서 AI가 **크롬 브라우저를 직접 움직이며** WOL을 조사하게 하려면 이 확장 프로그램을 설치하세요. 조사 과정을 눈으로 확인할 수 있습니다.

> **필요한 것:** Claude **유료 요금제**(Pro, Max, Team, Enterprise), **Google Chrome**, 컴퓨터. 모바일과 다른 브라우저는 지원하지 않습니다. 현재 베타 기능입니다.

1. 크롬에서 공식 확장 프로그램 페이지를 엽니다.
   👉 https://chromewebstore.google.com/detail/claude/fcoeoabgfenejglbffodgkkbkcdhcgfn
2. **Chrome에 추가**를 누릅니다.
3. 안내가 나오면 **Claude 계정으로 로그인**합니다.
4. 크롬 오른쪽 위의 퍼즐 조각(🧩) 아이콘을 누르고 **Claude 옆의 핀(📌)**을 눌러 고정합니다.
5. 요청하는 **권한을 허용**합니다.
6. 크롬에서 wol.jw.org를 열고, 툴바의 **Claude 아이콘**을 눌러 옆 패널을 엽니다.
7. 옆 패널에 기사 링크와 요청 문장을 보냅니다. ([사용 방법](#사용-방법) 참고)
   - wol.jw.org 접근을 허락할지 물어보면 **허용**합니다.

> ⚠️ 이름이 비슷한 다른 회사의 확장 프로그램(예: "Claude Toolbox")이 있습니다. 반드시 위 링크의 **Anthropic 공식** 확장 프로그램을 설치하세요.

## 사용 방법

새 대화(세션)에서 기사 링크와 함께 이렇게 보냅니다.

```
이번 주 파수대 기사야: https://wol.jw.org/ko/wol/d/r8/lp-ko/(기사번호)
1항부터 3항까지 기본해설, 부가해설, 연구해설로 정리해 줘.
```

이어서 이렇게도 요청할 수 있습니다.
- `4항부터 6항까지 이어서 해 줘`
- `5항 연구해설만 더 깊게 찾아 줘`
- `더 짧게, 30초 안에 말할 수 있게 줄여 줘`

### 이렇게 조사해요

| 단계 | 화면 |
|---|---|
| **① 기사 읽기**<br>항 번호, 질문, 인용 성구, 각주를 정리합니다. | <img src="docs/images/step1.png" width="300"> |
| **② WOL에서 검색**<br>항마다 키워드 2~3개로 검색합니다. 결과가 없으면 검색어를 줄여서 다시 검색합니다. | <img src="docs/images/step2.png" width="300"> |
| **③ 결과 고르기**<br>관련성이 높고 최근인 출판물부터 고릅니다. | <img src="docs/images/step3.png" width="300"> |
| **④ 열어서 읽기**<br>검색 결과의 짧은 발췌가 아니라 앞뒤 문맥까지 확인합니다. | <img src="docs/images/step4.png" width="300"> |
| **⑤ 정리**<br>조사 과정 표와 기본·부가·연구해설을 출처와 함께 씁니다. | <img src="docs/images/step5-result.png" width="300"> |

### 결과 예시

**1항: 사탄은 우리가 여호와께 등을 돌리게 하기 위해 어떤 방법을 사용합니까?**
- **기본해설**: 여호와와 예수께서 우리를 사랑하신다는 점에 의문을 갖게 만들어 우리가 스스로 등을 돌리게 하려고 합니다.
- **부가해설**: 사탄은 우리가 "사랑받을 가치가 없다"고 믿게 하려 합니다. 하지만 로마 8:38, 39은 어떤 것도 하느님의 사랑에서 우리를 갈라놓을 수 없다고 말합니다. (「파수대」 2019년 9월호 15항)
- **연구해설**: 희망이 닻이라면 믿음은 닻에 연결된 쇠사슬입니다. 의심을 해결하지 않으면 그 사슬이 녹슬어 약해집니다. (「파수대」 2021년 2월호 15-16항)

### 사용 팁
- **2~3항씩** 요청하세요. 한 번에 모두 요청하면 조사가 얕아집니다.
- 개인 경험이 들어가면 좋은 곳에는 `[개인 경험]` 자리만 표시해 줍니다.
- **최종 확인은 꼭 직접** 하세요. 출처를 WOL에서 열어 보고 사용하세요.
