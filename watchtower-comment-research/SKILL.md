# 파수대 연구 해설 조사

사용자는 집회에서 말할 해설을 준비하는 사람이다. 사용자가 가장 중시하는 것은 **검증 가능성**이다. 모든 내용은 사용자가 jw.org에서 직접 다시 찾아볼 수 있어야 한다. 그래서 아래 두 원칙이 다른 모든 것보다 우선한다.

## 원칙 1. jw.org / wol.jw.org 안에서만 조사한다

- 외부 사이트(바이블허브, 위키백과, 뉴스, 논문, 블로그 등)는 열지도, 검색하지도, 인용하지도 않는다. 일반 웹 검색 도구도 쓰지 않는다.
- 사용자는 외부 출처를 쓰면 해설로 쓸 수 없는 자료로 여긴다. 실제로 외부 사이트를 열었다가 사용자가 거부한 적이 있다.
- 자기 지식으로 원어 설명이나 역사 정보를 덧붙이고 싶다면, 같은 내용을 WOL에서 찾았을 때만 쓴다. 찾지 못하면 쓰지 않거나 "출처 확인 못 함"이라고 분명히 표시한다.
- 영어 WOL(`wol.jw.org/en/...`)은 jw.org 안이므로 사용해도 된다. 영문 연구용 성경의 연구 노트처럼 한국어판에 없는 자료를 찾을 때 유용하다.

## 원칙 2. 사람이 조사하듯이, 사용자가 볼 수 있게 한다

- 브라우저 도구가 있으면 브라우저를 사용한다. Claude 데스크톱 앱의 내장 브라우저나 Claude in Chrome이 여기에 해당한다. WOL 검색창에 키워드를 직접 입력하고, 결과를 클릭해서 열고, 해당 문단을 읽는다. 사용자가 그 과정을 지켜보면서 검증할 수 있게 하기 위해서다.
- 브라우저가 없는 환경도 있다. 예를 들어 Codex CLI나 터미널 전용 Claude Code가 그렇다. 이때는 웹 가져오기 도구나 `curl`로 wol.jw.org 주소(`references/wol.md`의 검색·성경 주소)만 직접 불러와서 읽는다. 검색엔진이 보여 주는 짧은 요약만 보고 쓰지 말고, 실제 WOL 페이지를 불러와 문맥을 확인한다.
- 작업 중간에 지금 무엇을 검색하고 무엇을 찾았는지 한 줄씩 알려 준다. 화면을 볼 수 없는 환경에서는 이 진행 보고와 조사 과정 표가 사용자의 유일한 검증 수단이 된다.
- 페이지 내용을 빨리 읽을 때는 wol.jw.org 페이지 안에서 JavaScript로 텍스트를 가져와도 된다.

## 작업 절차

1. **기사 원문 읽기**: 기사 링크를 열어 항 번호, 연구 질문, 인용 성구, 낭독 성구, 각주(a, b, c…), 삽화 설명, 복습 질문을 정리한다. 6-7항처럼 질문 하나가 두 항에 걸친 경우는 하나로 묶는다.
2. **항마다 키워드 2~3개 정하기**
   - 인용 성구의 핵심 표현 (예: "빛의 천사로 가장")
   - 성구의 이미지나 비유 (예: "의심 바다 물결")
   - 항의 핵심 논점을 짧게 줄인 말 (예: "사탄 사랑받을 가치")
3. **WOL에서 검색하기**: 주소 형식은 `references/wol.md`에 있다.
   - 결과가 0건이면 검색어를 2~3단어로 줄여서 다시 검색한다. 긴 문장은 거의 검색되지 않는다.
   - 결과가 많으면 최근 연구용 「파수대」, 「통찰」, 연구용 성경 연구 노트, 「성경을 검토함」 순서로 우선해서 고른다.
4. **실제로 열어 읽기**: 검색 결과에 보이는 짧은 발췌만 보고 쓰지 않는다. 기사를 열어 앞뒤 문맥까지 확인한다.
5. **성구와 각주 확인**: 인용하는 성구는 신세계역(연구용) 본문 페이지에서 표현과 각주를 확인한다. 각주에는 "또는 '…'", "직역하면 '…'" 같은 대체 번역이 있다. 이런 대체 번역은 연구해설의 좋은 재료가 된다.
6. **정리**: 아래 형식으로 결과를 쓴다.

## 결과 형식

먼저 조사 과정을 표로 보여 준다. 사용자가 같은 경로로 다시 찾아볼 수 있게 하기 위해서다.

| 순서 | 검색 키워드 | 결과 수 | 열어 본 자료 | 찾은 내용 |
|---|---|---|---|---|

그다음 항마다 이렇게 쓴다.

**N항: (연구 질문 그대로)**
- **기본해설**: 연구 질문에 바로 답하는 1~2문장. 기사 내용에 충실하게 쓴다.
- **부가해설**: 같은 항의 다른 성구나 다른 각도를 다루는 1~2문장. 출처가 있으면 함께 적는다.
- **연구해설**: 검색해서 찾은 출판물, 각주, 원어 설명을 근거로 한 1~3문장. 끝에 (출처)를 붙인다. 출처 예: 「파수대」 2021년 2월호 26-31면 15항, 「통찰」 1권 "사탄", 시편 118:5 각주

해설 작성 규칙:
- 실제 집회에서 말하는 구어체로, 30초 안에 말할 수 있는 길이로 쓴다. 사용자는 "짧게"를 원한다.
- 개인 경험이 들어가면 좋은 곳에는 내용을 지어내지 말고 [개인 경험]이라고 자리만 표시한다.
- 다음 기사 예고 같은 마지막 항은 기본해설만 써도 된다.
- 맨 끝에 **확인하지 못한 부분**을 적는다. 출판물에서 확인되지 않은 추론은 "본문에서 생각해 볼 수 있는 점"이라고 구분한다.

## 분량 조절

항이 18개쯤 되면 한 번에 모두 깊게 조사하기 어렵다. 사용자가 범위를 정하지 않았다면 먼저 1~3항 정도를 끝까지 조사해 보여 주고, 같은 방식으로 이어서 할지 묻는다. "1항부터 전부, 짧게"처럼 범위가 정해져 있으면 그 범위를 따른다. 이때도 성구와 각주 확인은 빠뜨리지 않는다.

## 예시 (2026년 10월 5-11일 기사의 1항)

| 순서 | 검색 키워드 | 결과 | 열어 본 자료 | 찾은 내용 |
|---|---|---|---|---|
| 1 | 빛의 천사로 가장 | 38건 | 「통찰」 1권 "사탄" | 사탄은 "본색과 목적을 감추고" 접근함 |
| 2 | 의심 바다 물결 | 33건 | 「파수대」 2021년 2월호 26-31면 | 의심은 닻을 연결하는 쇠사슬의 녹과 같음 |
| 3 | 사탄 여호와께서 사랑하지 않으신다 | 0건 | (검색어를 줄여서 다시 검색) | |
| 3-1 | 사탄 사랑받을 가치 | 3건 | 「파수대」 2019년 9월호 20-25면 15항 | 사탄은 우리가 "사랑받을 가치가 없다"고 믿게 하려 함 → 로마 8:38, 39 |

**1항: 사탄은 우리가 여호와께 등을 돌리게 하기 위해 어떤 방법을 사용합니까?**
- **기본해설**: 사탄은 우리가 여호와와 가까이 지내는 한 이길 수 없다는 걸 압니다. 그래서 여호와와 예수께서 우리를 사랑하신다는 점에 의문을 갖게 만들어 우리가 스스로 등을 돌리게 하려고 합니다.
- **부가해설**: 사탄은 우리가 "사랑받을 가치가 없다"고 믿게 하려 합니다. 하지만 로마 8:38, 39은 어떤 것도 하느님의 사랑에서 우리를 갈라놓을 수 없다고 말합니다. (「파수대」 2019년 9월호 15항)
- **연구해설**: 야고보 1:6은 의심하는 사람을 출렁이는 바다 물결에 비유합니다. 희망이 닻이라면 믿음은 닻에 연결된 쇠사슬인데, 의심을 해결하지 않으면 그 사슬이 녹슬어 약해집니다. 그래서 의심은 바로 해결해야 합니다. (「파수대」 2021년 2월호 26-31면 15-16항)
